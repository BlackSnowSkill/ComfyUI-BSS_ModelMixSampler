# ModelMixSampler (BSS) для ComfyUI

**ModelMixSampler (BSS)** — это продвинутая, оптимизированная кастомная нода для ComfyUI, которая позволяет поочередно чередовать шаги генерации (денойзинга) между двумя моделями **одинаковой латентной архитектуры** (например, SDXL с SDXL, или DiT с DiT, такие как HunyuanVideo и Wan2.1) в рамках одного процесса генерации.

Благодаря прямому переносу структуры латента и шума без промежуточного VAE-декодирования, нода обеспечивает максимальную скорость сэмплирования, 100% сочные цвета, высокую четкость деталей и абсолютное отсутствие паразитных цветовых искажений (синевы/артефактов).

## Ключевые особенности

1. **Микширование моделей одной архитектуры:**
   Смешивайте любые модели одинакового латентного пространства (например, две разные модели SDXL с 4 каналами, или две модели DiT: Flux, HunyuanVideo, Wan2.1 с 16 каналами).
2. **Максимальная скорость и отсутствие артефактов:**
   Поскольку латентное пространство моделей совпадает, перенос шагов происходит напрямую без медленного кросс-VAE перекодирования. Это сохраняет идеальную цветопередачу и оригинальный контраст.
3. **Строгая валидация на входе:**
   Нода автоматически сверяет количество каналов (`c1 == c2`) и пространственную размерность латента (`dim1 == dim2`). При несовпадении выдается чёткое информативное предупреждение, что защищает от неожиданных сбоев `RuntimeError` во время работы.
4. **Математически точное масштабирование шума (Noise Scaling):**
   Вызывает одношаговые обертки денойзинга, позволяя родному механизму планирования каждой модели правильно транслировать шум латента на каждом шаге $\sigma_i$.
5. **Совместимость с EPS и Flow/CONST (Flux, Hunyuan, Wan, SDXL):**
   Автоматически переключает характер подачи промежуточного шума на шагах $i > 0$:
   - Для моделей **EPS** (SDXL, SD1.5): подается нулевой шум `zeros`, чтобы KSampler не добавлял новый шум.
   - Для моделей **Flow/CONST** (Flux, HunyuanVideo, Wan2.1): подается сам текущий латент `current_latent`, что компенсирует встроенное умножение на $(1 - \sigma)$ и делает промежуточный шаг математически чистым тождеством (Identity).
6. **Уникальный пошаговый сидинг (Step Seeding):**
   Модулирует случайный сид инкрементально на каждом шаге (`seed + i`), что гарантирует, что стохастические семплеры (такие как `euler_ancestral` или `dpmpp_sde`) генерируют свежий шум без фазовых конфликтов или регулярных артефактов.
7. **Оптимизация памяти VRAM GPU:**
   Предварительно загружает обе модели на GPU одновременно с помощью `comfy.model_management.load_models_gpu([model1, model2])`, чтобы избежать медленного переключения моделей во время сэмплинга.
8. **Гибкий планировщик шагов (Mix Schedule):**
   Поддерживает мощный синтаксис парсинга для планов чередования шагов:
   - `1, 2` (чередование шагов: 1, 2, 1, 2...)
   - `1, 1, 2, 2` (два шага первой модели, два шага второй...)
   - `1*15, 2*15` (первые 15 шагов — модель 1, следующие 15 — модель 2)
   - `1:10, 2:15` (первые 10 шагов — модель 1, следующие 15 — модель 2)

## Установка

1. Скопируйте папку `ComfyUI-BSS_ModelMixSampler` в директорию кастомных нод ComfyUI:
   ```text
   ComfyUI/custom_nodes/
   ```
2. Перезапустите ComfyUI. Ноды загрузятся автоматически!

## Описание Нод

### 1. `ModelMixSampler (BSS)`
Основной сэмплер для пошагового смешивания моделей одной архитектуры.

**Параметры:**
- **`model1` / `model2`:** Две смешиваемые модели одинаковой латентной структуры.
- **`seed`:** Базовый сид генерации.
- **`steps`:** Общее количество шагов сэмплинга.
- **`cfg1` / `cfg2`:** Значения CFG для каждой модели.
- **`sampler_name1` / `sampler_name2`:** Алгоритм сэмплинга для каждой модели.
- **`scheduler`:** Общий планировщик уровней шума.
- **`positive1` / `negative1` / `positive2` / `negative2`:** Соответствующие промпты/кондишены.
- **`latent_image`:** Начальный латентный образ.
- **`denoise`:** Сила денойзинга (img2img).
- **`mix_schedule`:** Паттерн шагов (например, `"1, 2"` или `"1*15, 2*15"`).
- **`vae1` / `vae2` (опционально):** Сохранены для полной обратной совместимости существующих workflows (в цикле генерации игнорируются).

### 2. `ModelMixVAEDecode (BSS)`
Умная нода для безопасного декодирования латентов любой размерности (4D или 5D) с использованием VAE любой архитектуры (2D-изображения или 3D-видео). Автоматически выбирает VAE на основе каналов латента и безопасно адаптирует размерность тензора, предотвращая ошибки `IndexError`.
